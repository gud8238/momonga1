# 모몽가의 작은세계

하늘을 나는 모몽가가 되어 숲, 마을, 동굴, 열대우림을 탐험하는 3D 웹 게임입니다.
다른 플레이어와 같은 세계에서 함께 날아다니며 모험할 수 있어요.

## 시작하기
1. 인트로 화면에서 **게임 시작**을 누릅니다.
2. 이름(2~12글자)을 입력합니다.
3. **함께 모험하기**를 눌러 세계로 들어갑니다.

## 조작법
| 키 / 동작 | 기능 |
|---|---|
| W A S D | 이동 |
| Q (누르고 있기) | 상승 · 활강 (놓으면 서서히 하강) |
| E | 빠른 하강 |
| R | 공격 |
| 마우스 드래그 | 카메라 회전 |
| 마우스 휠 | 카메라 거리 조절 |
| 클릭 | NPC 대화, 음식·보상 줍기 |

## 함께 플레이하기
- 최대 20명이 한 세계에 모여 네 개의 맵을 함께 탐험합니다.
- 같은 맵에 있는 플레이어의 이름과 움직임, 비행, 공격 모습이 보입니다.
- **인사**와 **응원** 버튼으로 다른 플레이어에게 반응할 수 있어요.
- NPC 대화, 보스 토벌, 체력, 음식, 인벤토리, 의뢰는 각자 따로 진행됩니다.

## 즐길 거리
- **보스 토벌**: 동굴에는 아노코, 열대우림에는 세이렌이 나타납니다. 토벌을 수락하면 전투가 시작되고, 보스를 쓰러뜨리면 필드에 보상이 떨어집니다. 클릭해서 주워 보세요.
- **숲의 음식**: 숲 곳곳에 있는 음식을 모을 수 있습니다.
- **마을 의뢰와 상점**: 마을 NPC의 의뢰를 해결하고, 모은 아이템을 팔 수 있습니다.
- **낮과 밤**: 맵마다 낮과 밤의 분위기와 배경음악이 달라집니다.
- **사운드**: 소리 켜기 버튼을 누르면 배경음악, 캐릭터 음성, 공격·피격·물보라 효과음이 재생됩니다.

## 알아두세요
- 게임 기록은 저장되지 않습니다. 새로고침하거나 다시 접속하면 새 게임으로 시작합니다.
- **나가기**를 누르면 게임이 끝나고 첫 화면으로 돌아갑니다.
